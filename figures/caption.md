Response features, modal frequency, and inspection history at Painter Street Overpass. (a) Peak response acceleration and ordinary cumulative absolute velocity (CAV) for 22 earthquakes; shading is the nominal 95% log-Gaussian envelope fitted to eight weak-motion reference events. (b) Change in the 3.38 Hz vertical mode relative to its reference frequency versus peak input PGA. The line is a weighted log-frequency fit; shading is an approximate 95% coefficient interval including covariance. Open circles indicate reference events, blue circles other test events, and orange triangles test events outside the envelope. (c) NBI component ratings by inspection date using the latest published value; hollow symbols mark revisions without a changed inspection date. Lines connect records and do not establish when physical changes occurred. Earthquake response departures and inspection changes do not independently establish earthquake damage.
